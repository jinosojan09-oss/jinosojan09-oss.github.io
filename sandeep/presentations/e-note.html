What is E-Note?

E-Note is a Flutter mobile app that remotely controls an ESP32-powered e-paper desk display. Users can manage todos and push messages from their phone, which sync in real time to a physical screen on their desk via Firebase. This presentation focuses on the Flutter app: its architecture, UI design, state management, and Firebase integration. Flutter App Cross-platform (Android & iOS) GetX state management Firebase Realtime Database Material Design UI

App Features

Todo Management Create, edit, delete, and reorder to-do items. Changes push instantly to the desk display. Message Push Type custom messages in the app and send them to the e-paper screen with one tap. Device Status Monitor the ESP32 connection status and display health in real time from the app. Live Sync Firebase streams keep the app and display perfectly in sync with zero manual refresh. Firebase Integration

The app uses Firebase Realtime Database to sync data between the mobile app and the ESP32 hardware. Every change in the app is instantly reflected on the desk display. 1 User creates/edits a todo or message in the app 2 App writes data to Firebase RTDB as JSON 3 Firebase triggers stream update to all listeners 4 ESP32 receives data and refreshes the e-paper display Database Structure enote/ todos/ todo_1: { "title": "Buy groceries", "done": false } messages/ msg_1: { "text": "Meeting at 3PM", "timestamp": 1715... } device/ "status": "online", "lastSync": 1715...
