Certification Overview

Grounding an LLM with retrieved knowledge

RAG brings retrieved reference material into the generation process to make AI responses more grounded.

RAG Architecture

Retrieve → Augment → Generate

  • Retrieve relevant documents
  • Supply retrieved context to the model
  • Generate an answer using the context
Embeddings & Vector Databases

Finding relevant context

  • Represent source material with embeddings
  • Store and retrieve related information
  • Use semantic search for relevant context
Building a RAG Workflow

End-to-end knowledge retrieval

  • Prepare and organize source documents
  • Retrieve supporting passages
  • Feed passages into an LLM for answering
Reliability

Reducing unsupported responses

  • Ground claims in factual, retrieved context
  • Check the retrieved information
  • Evaluate output quality and source relevance
