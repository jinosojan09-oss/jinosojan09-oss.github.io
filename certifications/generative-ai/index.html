Certification Overview

Working with language models

This badge focuses on understanding how LLMs work with natural language, structured data, and unstructured information.

Understanding LLMs

Processing information

  • Understand natural language questions
  • Explore how LLMs work with structured and unstructured datasets
  • Use model outputs to identify patterns and insights
Prompt Engineering

From prompts to useful insights

  • Write clear, contextual prompts
  • Extract insights from datasets
  • Refine instructions and evaluate the response
Practical Applications

Using generative AI for data workflows

  • Summarize text and data
  • Interpret results for decision support
  • Consider business-intelligence applications
Evaluation & Takeaways

Accuracy, relevance and responsible review

  • Evaluate outputs instead of assuming correctness
  • Check whether responses answer the intended question
  • Use prompts and data context together
