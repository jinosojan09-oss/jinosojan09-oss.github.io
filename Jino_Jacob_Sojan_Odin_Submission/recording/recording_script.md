# Screen-recording plan (record in your own voice)

## Video 1: Intermediate HTML & CSS (4–6 min)
Introduce CSS Grid, Flexbox, responsive design, form accessibility and validation. Show the sign-up form: try an invalid email and mismatched passwords. Show the dashboard at desktop and mobile width. Explain your own modifications.

## Video 2: JavaScript Basics (5–7 min)
Explain variables (`let`/`const`), primitive values, conditionals, functions, arrays, loops, DOM selection and event listeners. Open `signup/app.js` and point to `addEventListener`, `preventDefault`, and `checkValidity`. Explain why client-side validation is not a secure backend.

## Video 3: JavaScript course (7–10 min)
Explain object constructors with `new Book(...)`; show adding, toggling, deleting and refreshing the Library page. Explain localStorage and the DOM rendering method. Open Tic Tac Toe; demonstrate turns, a win, a draw, and reset. Explain the module's private state and win combinations.

## Video 4: Portfolio and AI idea (4–6 min)
Show profile, activities, project cards, Odin sections and homework. Open GitHub repository and live GitHub Pages URL (once published). Present the AI Study Companion proposal: user need, features, privacy, architecture and next steps.

## Recording checklist
- Record screen and microphone with OBS Studio or another screen recorder.
- Speak naturally; demonstrate both code and working browser output.
- Show your own name, repo URL, and actual course evidence.
- Save MP4s and upload to your own Drive/YouTube or GitHub Releases; paste links in portfolio.
- Never claim an uncompleted course or unrecorded demo is finished.

## Video 5: Advanced HTML & CSS overview (3–5 min)
Explain responsive design, CSS Grid/Flexbox, accessibility and media queries. Show the dashboard at different widths and explain which techniques you actually used.

## Instructor questions to practice
1. Why use `new Book(...)` and what does the constructor initialize?
2. How is localStorage different from an array in memory?
3. What is a closure? How does the Tic Tac Toe module hide state?
4. How do you detect a win or a draw?
5. How does event delegation differ from attaching listeners to every element?
6. Why must a production application validate inputs on the server too?
